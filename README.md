# NTM IQ Expansion

The new content of **NTM: IQ Edition** (1.7.10), ported to **Minecraft 1.12.2** as an add-on for **HBM's Nuclear Tech
Mod Community Edition** — new blocks, items and machines from IQ Edition, running alongside the 1.12.2 NTM.

## Compile-only jars

The build compiles against these jars in `libs/` (other authors' mods / APIs). They are not included in this repo — get them from their official pages and drop them in `libs/` before building:

- `NTM-CE-1.12.2-2.5.0.5.jar`
